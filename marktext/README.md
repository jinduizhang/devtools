# MarkText 工具集

[MarkText](https://github.com/marktext/marktext) 是一款免费开源的桌面 Markdown 编辑器/查看器，所见即所得实时预览，跨平台（Windows / macOS / Linux），定位是 Typora 的开源替代品。

> 截至 2026-09-06，实测版本 v0.19.1，Windows x64。

| [install.md](install.md) | Windows 安装说明（镜像下载、SHA256 校验、静默安装、中文界面切换、`.md` 关联） |

## 一句话总结

- **它只做 Markdown**：不是笔记库、不是知识库，专注把 `.md` 写好看、打开快。
- **内置简体中文**：仓库 `packages/desktop/static/locales/zh-CN.json` 即官方简中语言包，无需汉化补丁，设置里切即可。
- **GitHub 直连不稳时走镜像前缀下载**（方案见仓库根目录 [github-proxy.md](../github-proxy.md)）。
